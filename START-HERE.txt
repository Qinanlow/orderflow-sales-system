Wura Sales Order & Invoicing System Prototype

現有 GitHub／Firebase 專案：
1. 只需以新版 site.zip 覆蓋 GitHub main 分支的舊檔。
2. GitHub Actions 會自動發布網站及 Firestore 規則。

第一次建立新專案：
1. 解壓本交付 ZIP。
2. 把解壓後的全部內容上傳到 GitHub main 分支。
3. 依 README.md 在 Firebase 開啟 Anonymous Auth、Firestore，並新增三個 GitHub 設定。
4. 執行 GitHub Actions。

切勿把 Firebase service account 私鑰放進 ZIP 或 GitHub 檔案；只能放在 GitHub Secret。
